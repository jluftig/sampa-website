# Website update — SAMPA Board agenda item

**For:** SAMPA Board meeting  
**Prepared:** August 9, 2026  
**Site:** [www.addictionpas.org](https://www.addictionpas.org)

## Agenda item

**Website progress update** — overview of features now live on the SAMPA website (and companion mobile app), July–August 2026.

### Recently added / now live

- **Public newsletter signup (SAMPA Updates)** — Visitors can subscribe without becoming members. Double opt-in confirmation is live; confirmed subscribers join the SAMPA Updates list.
- **Member networking directory** — Active members can browse peer profiles (`/members`), with opt-out, optional contact sharing, and multi-organization work history (role, city/state, website).
- **Practice-setting chips & directory filter** — Members tag employers with curated settings (e.g. ED, outpatient); soft color chips on profiles; directory can filter by setting.
- **Board badge** — Directory shows a Board badge for members flagged as board (`is_board`); further board-only tools not built yet.
- **Member discussion on news** — Active members can leave comments and emoji reactions on published news posts (web and mobile); public can read on published posts.
- **Ordered co-authors on news** — Editors can assign multiple authors in order; article bylines reflect that order.
- **News / blog + Key Points research database** — Editor dashboard, keyword browse and intersections, full-text search, per-claim share links, and social preview cards.
- **Policy hub** — Public `/policy` with SAMPA’s HHS RFI public comment (PDF + summary), access-focused framing, and a clear roadmap of levers (telehealth, state/OTP alignment, workforce, payment, stigma/peers, data). Nav label remains **Policy**.
- **About page & Ad Grants readiness** — Dedicated `/about` with mission, 501(c)(3) / EIN, live vs in-development programs, and clearer Join / Donate paths on the homepage.
- **Tax-deductible donations restored** — After SAMPA, Inc. received 501(c)(3) determination (EIN 42-2288772), `/donate` supports one-time and monthly giving with tax-deductible disclosure.
- **Member area + Stripe memberships** — Google / magic-link sign-in, `/join` checkout, member dashboard (billing portal, account vs directory profile, saved articles), tiered multi-year pricing, and admin roster with pledge tracking / CSV export.
- **Privacy & Terms** — Updated for the member directory (effective July 11, 2026); directory use and disclosure called out for a small nonprofit context.
- **Merch store link** — Nav/footer and `/store` redirect to the Printful storefront.
- **Mobile app (code live; public store launch pending)** — Expo app shares the same backend: news, Key Points, keywords/search, saved articles, auth, member area, directory, and push when a post is published. TestFlight / App Store rollout still in progress (Apple org conversion and board testing remain).

### In progress (not yet fully public)

- **Weekly email campaigns (Brevo)** — Domain authenticated; SAMPA Weekly Issue 01 drafted and tested. First production send awaits board/leadership approval.
- **Member welcome / renewal / donation thank-you emails** — Automation path built; needs production Brevo key confirmation and final go-ahead.
- **Buprenorphine dosing + COWS tool** — Built on a feature branch; on clinical review hold before public launch.
- **iOS / Android public launch** — Waiting on Apple organization conversion (D-U-N-S), TestFlight validation, and App Store assets.
